# Интернет‑магазин — InternetMagazine
Простой интернет‑магазин с управлением товарами и категориями.

## Функциональность
Система позволяет:
- создавать товары (Product) с указанием названия, описания, цены и количества;
- создавать категории (Category) и группировать в них товары;
- автоматически вести подсчёт:
  - общего числа категорий;
  - общего числа товаров во всех категориях.
Контроль корректности цены
В классе Product реализован механизм валидации цены:
- цена не может быть нулевой или отрицательной — при попытке установить такое значение выводится предупреждение;
- при понижении цены требуется подтверждение через интерактивный ввод (да/нет).

Приватные атрибуты и контролируемый доступ
Реализована защита данных через:
- приватные атрибуты (__products, __price) для предотвращения прямого изменения извне;
- геттеры и сеттеры для безопасного доступа и модификации данных.

Также реализовано чтение данных с файла:
  - `read_json` - чтение данных из файла формата .json

## Установка
1. Клонируйте репозиторий:

```
git clone https://github.com/Sofya-Ageeva/InternetMagazine.git
```

2. Установите зависимости:

```
pip install requirements.txt
```

## Тестирование существующих функций
1. Реализованы тесты c покрытием кода более чем на 75 %.
2. В тестах добавлены фикстуры.
3. Для запуска теста необходимо ввести в командной строке следующую команду:
```
pytest
```
4. Для генерации отчета с помощью pytest установите pytest-cov:
```
pip install pytest-cov
```
Для запуска отчета:

```
pytest --cov=src tests/
```
или для открытия отчета в браузере
```
pytest --cov=src --cov-report=html tests/
```
5. Результаты тестирования содержаться в папке `htmlcov/`)
После выполнения откройте htmlcov/index.html в браузере.
